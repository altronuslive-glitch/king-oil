# King-Oil — вёрстка интернет-магазина

Статическая вёрстка магазина автомасел по макету Figma. Без сборщика и зависимостей:
в браузер уходит готовый HTML из `src/`. Позже вёрстка переносится в CS-Cart.

## Быстрый старт

```bash
python dev-server.py      # локальный сервер без кэша, http://localhost:5173
```

## Структура

| Папка / файл | Что внутри |
| --- | --- |
| `src/` | Готовая статика: страницы, `css/`, `js/`, `img/`. Её и открывает браузер |
| `partials/` | Общие блоки: шапка, футер, таббар, модалки, спрайт |
| `build-pages.py` | Раскладывает `partials/` по страницам в маркеры `<!-- @shared:NAME -->` |
| `build-sprite.py` | Пересобирает SVG-спрайт `partials/sprite.html` |
| `docs/` | Разбор макета по страницам и компонентам, журнал решений |
| `figma-refs/` | Скриншоты макета для сверки |

После правки любого файла в `partials/` нужно выполнить `python build-pages.py`.

## Страницы

Главная, каталог (раздел и листинг категории), карточка товара, корзина, оформление
и статус заказа, избранное, поиск, акции и акция, доставка, оплата, как купить, возврат,
о компании, отзывы, контакты, личный кабинет, юридическая страница, 404.

## Правила работы

Вёрстка пиксель-перфект по макету: размеры снимаются из Figma, проверяются замером
в браузере, значения пишутся токенами `--ko-*`. Любое отклонение от макета фиксируется
комментарием в коде и записью в `docs/`. Подробности — в [CLAUDE.md](CLAUDE.md)
и [docs/README.md](docs/README.md).
