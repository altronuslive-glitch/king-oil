Проверено 3 сентября 2026 года. ## Что поправлено по ходу сверки

1. **Высота контролов.** У общего `.input` и `.select` рамка лежит поверх паддинга, и в сумме получается 54, а в макете 52. В подборе по авто, фильтрах и форме обратной связи высота зафиксирована явно.
2. **Лента отзывов.** Правило `.reviews .carousel { grid-auto-columns: 650px }` лежало в `home.css`, поэтому в каталоге и на товаре карточки отзывов схлопывались до 332. Переехало в `components.css` — к самому компоненту.
3. **Таблица реквизитов.** Паддинг ячеек 16 → 20, строка стала 64 вместо 56, ближе к макету.
4. **Тёмная CTA-полоса.** Вертикальный паддинг 48 → 64, высота 184 → 216 (в макете 212).

## Осознанные отклонения

| Что | Почему |
|---|---|
| **Крошки 62 вместо 68** | Высота задана паддингом 20 и строкой `Caption xl` 15/22. Ровно 68 получится только жёсткой высотой, которая сломается на двухстрочных крошках. |
| **Карточки доставки 318 вместо 316** | Заголовок `Heading 6` и описание `Caption xl` дают на 2 px больше, чем в макете, — округление межстрочного. |
| **FAQ 722 вместо 738** | Высота аккордеона зависит от длины ответа в раскрытом пункте. Тексты временные, см. [13-open-questions.md](13-open-questions.md). |
| **Кнопка «В корзину» 127 вместо 137** | Ширина по содержимому: в макете у кнопки другой внутренний отступ под тот же текст. |
| **Иконки способов доставки** | В макете все четыре — молния из проекта по окнам. Поставлены осмысленные: грузовик, метка, коробка, молния. Две первые нарисованы вручную, см. [15-icons.md](15-icons.md). |
| **Мобильные фильтры каталога** | Макета нет. Сделана кнопка «Фильтры», раскрывающая ряд селектов на ширину экрана. Требует согласования. |

## Как повторить проверку

```bash
python dev-server.py
```

В браузере на вьюпорте 1915 выполнить в консоли:

```js
const R = s => { const r = document.querySelector(s).getBoundingClientRect(); return `${Math.round(r.width)}x${Math.round(r.height)} @${Math.round(r.left + scrollX)},${Math.round(r.top + scrollY)}`; };
R('.car-picker'); // ожидаем 1420x230 @240,350
```
