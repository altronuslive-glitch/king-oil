# King-Oil — документация макетов для вёрстки

Источник: Figma-файл [kingoil.itb-dev.ru](https://www.figma.com/design/fUUdaKDxudos0ygbHbKCNF/kingoil.itb-dev.ru?node-id=22997-107243), страница **«▶ Design»** (`22997:107243`).
Данные сняты через официальный Figma MCP 3 сентября 2026 года: размеры и координаты — из метаданных Figma (не на глаз), цвета и типографика — из Figma Variables.

## Как пользоваться

1. **Начни с [01-tokens.md](01-tokens.md)** — там вся система: цвета, шрифты, отступы, сетка. Готовый CSS — в [tokens.css](tokens.css), его можно подключить как есть.
2. Дальше бери документ по нужному блоку. В каждом: скриншот, точные размеры в пикселях, состав элементов и поведение.
3. Все размеры даны для **десктопного артборда 1900 px**. Контейнер — 1420 px, боковые поля — 240 px.
4. Node ID указан у каждого блока — по нему открывается конкретный слой:
   `https://www.figma.com/design/fUUdaKDxudos0ygbHbKCNF/?node-id=26701-7944` (двоеточие в ID меняется на дефис).

## Что готово в макете, а что нет

**Есть:** 7 десктопных страниц, шапка со всеми состояниями (десктоп + мобайл), полный набор модалок в двух ширинах, футер, наборы карточек товаров и статей.

**Нет:** мобильных и планшетных версий страниц целиком (только компоненты), состояний загрузки и пустых состояний каталога, страниц корзины, оформления заказа и личного кабинета, страницы 404.

Подробности — в [13-open-questions.md](13-open-questions.md).
