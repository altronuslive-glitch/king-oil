# 00. Договорённости по проекту

Зафиксировано 3 сентября 2026 года.

## Решения

| Вопрос | Решение |
|---|---|
| **Формат** | Статическая вёрстка HTML/CSS/JS, интеграция в CS-Cart отдельным этапом |
| **Порядок работ** | Фундамент (токены, сетка, шапка, футер) → главная → остальные страницы |
| **Адаптив** | Десктоп + планшет + мобайл. Брейкпоинты **1440 / 1024 / 768 / 480**. Планшетные раскладки придумываем сами по логике макета, потом показываем на согласование |
| **Шрифт** | Inter, локальные `.woff2`, начертания 400 / 500 / 600 с кириллицей |
| **Браузеры** | Современные, последние 2 года. Можно `grid`, `:has()`, `line-clamp`, container queries, вложенный CSS |
| **Чужой контент** | Заменяем на осмысленные заглушки по теме масел, каждую помечаем `<!-- TODO: контент -->` |
| **Скоуп** | Только 7 страниц из макета. Корзина, чекаут, ЛК, 404 — отдельный этап после макетов |
| **Хранение** | Локальный git-репозиторий, готовое выкладываем по SSH на тестовый сервер |

## Общие блоки страниц

Шапка, футер, таббар, спрайт, модалки, лента отзывов, форма «Напишите нам» и
FAQ повторяются на нескольких страницах. Чтобы не править их в семи файлах,
каждый лежит отдельным файлом в `partials/`, а на странице стоит пара
комментариев:

```html
<!-- @shared:header -->
<!-- /@shared:header -->
```

`python build-pages.py` подставляет содержимое между ними. Страницы при этом
остаются обычным статическим HTML: в браузер и на сервер уходит готовый файл,
сборка нужна только при правке общего блока.

## Куда выкладываем

Тестовый сервер, отдельная подпапка, чтобы не задеть текущий CS-Cart:
`/var/www/developer2356/data/www/kingoil.itb-dev.ru/layout/`
→ будет доступно по `https://kingoil.itb-dev.ru/layout/` (под той же Basic-авторизацией `itb` / `1q2w3e4r`).

Точный путь подтвердить перед первой выкладкой.

## Порядок этапов

1. **Фундамент** — `tokens.css`, `base.css`, контейнер, сетка, шрифты, типографика
2. **Шапка** — десктоп (7 состояний), мобайл (бургер, таббар), мега-меню, поиск, мини-модалки
3. **Футер** — включая мобильную раскладку
4. **Модалки** — общий движок + 15 наборов
5. **Главная** — 8 секций
6. **Каталог** и **карточка товара** — самые сложные
7. **Акции, доставка, контакты, о компании**
8. **Прогон адаптива** по всем брейкпоинтам, проверка в браузере
