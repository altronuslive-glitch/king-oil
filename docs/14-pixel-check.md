# 14. Пиксельная сверка главной с макетом

Проверено 3 сентября 2026 года. Метод: замер через `getBoundingClientRect()` в браузере на вьюпорте **1900 px** — там контейнер вёрстки (1420) и боковые поля (240) совпадают с артбордом Figma один в один. Эталонные координаты взяты из метаданных Figma, не с картинки.

Из всех измеренных X вычтено 7 px — на столько контейнер смещён влево из-за полосы прокрутки браузера (1900 − 15 = 1885 полезной ширины). В Figma полосы прокрутки нет.

## Что было исправлено по итогам сверки

1. **Заголовки секций** — стояли Heading 2 (64/72), в макете Heading 3 (48/52). Заменено в шести секциях.
2. **Заголовок слайдера** — стоял Heading 3, в макете Heading 2. Заменено.
3. **Названия категорий** — были 24/32, в макете 32/38.
4. **Цифры** — значение было 64/72, в макете 80/100; подпись была 18/24, в макете 32/38.
5. **Секция «Цифры»** — была свёрстана в две колонки, в макете заголовок над строками.
6. **Колонки категорий** — были резиновыми, в макете фиксированные 380 / 150 / 275 / 32 с гэпом 32.
7. **Подложка карточки товара** — была квадратной, в макете 460×360 с полями 40 вокруг изображения; во втором ряду 340×240.
8. **Название товара** — обрезалось в две строки, в макете одна строка 16/28.
9. **Стрелки каруселей** — были 40×40 с гэпом 8, в макете 48×48 вплотную (общая ширина 96).
10. **Индикатор карусели** — был резиновым, в макете полоса 79×6, прижатая к верху ряда.
11. **Вертикальные отступы секций** — были одинаковые 80, в макете нерегулярные: 120 у категорий, 120 снизу у сертификатов, 120/120 у тёмного блока, 160 сверху у отзывов, 160 снизу у акций.
12. **Логотип** — занимал 160×40, в макете блок 160×52.
13. **Гэпы в шапке** — были одинаковые 32, в макете логотип —32— «Каталог» —12— поиск —24— иконки.
14. **Колонки футера** — последняя была резиновой, в макете 263 с распределением по ширине; соцсети прижаты к низу.
15. **Карточка отзыва** — паддинг 24 → 32, звёзды 16 → 24, аватар 40 → 60, высота 384.
16. **Секция «Акции»** — была статичной сеткой, в макете карусель с индикатором и стрелками.
17. **Кнопка «Каталог»** — ширина по содержимому, в макете фиксированные 155.

## Баннер — отдельная сверка

18. **Фон баннера** — стоял плоский тёмный цвет, в макете на всю ширину лежит фотография (масло из канистры). Выгружена в `src/img/hero.jpg`, 1920×594, 67 КБ. Вертикальная привязка кадра выверена по положению струи масла: совпадает пиксель в пиксель (верх струи на y=295 в обоих). По горизонтали кадр отличается примерно на 19 px — так лежит заливка в макете; на композицию не влияет.
19. **Стрелки баннера** — были прозрачными с белой рамкой, в макете это **сплошные белые квадраты** 52×52 с тёмным шевроном и гэпом 10. Проверено: заливка `#ffffff`, шеврон `#131927`, границы 1546…1659.
20. **Кнопка «Перейти в каталог»** — совпадает: 200×52 на x=240, y=472.
21. **Текст лида** — было «от авторизованных дистрибьюторов», в макете «от авторизованных поставщиков».

## Осознанные отклонения

| Что | Почему |
|---|---|
| **Отступ от надзаголовка до заголовка — везде 16** | В макете 16 в трёх секциях (категории, цифры, сертификаты) и 14 в двух (отзывы, акции). Это разнобой дизайнера. Взят 16 как преобладающий — отсюда +2 px в двух секциях и +4 px по высоте страницы. Если нужно повторить в точности, скажи. |
| **Мега-меню 481 вместо 480** | Округление при вычислении высоты из содержимого. |
| **Ширина текстовых блоков в шапке** | Телефон и e-mail в макете — другие строки («internet@gmail.com» против «info@king-oil.ru»). Позиция правого края совпадает, ширина отличается из-за контента. |
| **Полоса категорий в шапке** | В компоненте Figma лежат 6 плейсхолдеров с шагом 183, на страницах — 8 реальных пунктов с другим шагом. Свёрстано по страницам, гэп 32. |
| **Смещение всей вёрстки на 7 px** | Полоса прокрутки браузера. В Figma её нет. При проверке нужно либо учитывать это, либо смотреть на `1900 − ширина полосы`. |
| **Кадр фонового фото сдвинут на 19 px по горизонтали** | Так позиционирована заливка в макете. Вертикаль выверена точно, композиция совпадает. |
| **Затемняющий градиент поверх фото баннера** | В макете его нет — там кадр сам по себе тёмный слева. На узких экранах кадр смещается, и заголовок попадает на светлую канистру, поэтому добавлен градиент, невидимый на десктопе. |
| **Шеврон в стрелках баннера на 1 px тоньше** | В макете два веса шевронов — 1.5 и 2. Использован 1.5, как в каруселях, чтобы не плодить дубли иконки. |

## Как повторить проверку

```bash
python -m http.server 5173 -d src
```

Дальше в браузере на вьюпорте 1900 выполнить в консоли:

```js
const R = s => { const r = document.querySelector(s).getBoundingClientRect(); return `${Math.round(r.width)}x${Math.round(r.height)} @${Math.round(r.left+scrollX+7)},${Math.round(r.top+scrollY)}`; };
R('.hero__content'); // ожидаем 700x460 @240,224
```
