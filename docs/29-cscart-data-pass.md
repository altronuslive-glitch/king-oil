# 29. Данные витрины «Омск» в вёрстке — 11 сентября 2026

Заход сразу после аудита админки ([28-admin-audit.md](28-admin-audit.md)). Заказчик
решил: **артикулы убираем, чипсы объёма делаем ссылками на соответствующий товар,
остальные данные приводим к каталогу CS-Cart.** Перенос вёрстки на стенд по его же
просьбе **не начат** — это следующий этап, чек-лист в конце документа.

Источник данных — снимок витрины «Омск» в [data/](data/) (416 активных товаров,
80 категорий, 11.09.2026). Счётчики разделов сверены запросом к базе стенда.

## Как это теперь устроено (для переноса в Smarty)

- **Плитка** — `data-product-id`, в листинге ещё `data-viscosity` / `data-type` /
  `data-brand` / `data-approval` / `data-volume`. Название, цена, старая цена — как
  в CS-Cart, объём — часть названия, отдельно к названию нигде не дописывается.
- **Чипсы объёма** — соседние товары: те, у кого название совпадает с точностью до
  объёма (`4л`, `4 л`, `4L`, `5кг`, «Розлив» = 1 л). В снимке таких групп с двумя и более
  объёмами 28 (57 товаров из 416). У товара без «соседей» один чипс-подпись, без объёма
  в названии (аккумуляторы, фильтры, лампы) — чипсов нет. В CS-Cart это можно сделать
  либо характеристикой «Объём» + связкой «Вариации», либо тем же поиском по названию —
  вопрос №52 больше не блокер.
- **Остаток** — признак «есть / нет»: `data-stock="1"`, число не показывается,
  степпер до 99, позиция корзины `max: 99`.
- **Корзина и избранное** — ключ `product_id`. «В корзину» с плитки, из избранного
  и из карточки товара даёт одну и ту же позицию.
- **Артикулов нет** — ни в разметке, ни в параметрах, ни в состоянии.

## Что нашлось в данных (передать заказчику)

Названия в каталоге ведутся руками, встречаются опечатки и разнобой. В вёрстке они
оставлены как есть — это реальные данные:

- 3964 «Лукойл **Genesisc** Armortech 0w-40 1l (Розлив)», 3585 «**Gazpromnefr** Super
  10w40 (Розлив)», 3086 «Takayama 5w30  ILSAC-GF5 (Розлив )» — двойной пробел и пробел
  перед скобкой;
- 296 «Castrol Magnatec 5W40 **А3/В4**» — «А» и «В» кириллицей;
- регистр брендов гуляет: «CASTROL 5W-30 MAGNATEC AP 4L» рядом с «Castrol Magnatec C3
  5W40 4l», «Розлив» / «розлив» / «(Розлив )»;
- у 3631 «Eneos Premium Touring 5w30 (Розлив)» старая цена 650 ₽ **ниже** цены 690 ₽ —
  бейдж скидки не показывается;
- старая цена есть только у 9 товаров, бейджи «−N%» появятся редко (вопрос №55 — это
  нормально, бейдж и зачёркнутая цена скрываются, когда старой цены нет).

Картинки плиток — по-прежнему демо-фото из `img/products/`; при переносе они заменятся
изображениями товаров CS-Cart (у 296 их четыре).

## Что осталось — чек-лист следующего этапа

К переносу можно приступать: блокеров нет, вёрстка привязана к ID CS-Cart. Порядок
по [25-cscart-integration.md](25-cscart-integration.md) с поправками аудита:

**Перед переносом (решения заказчика, не блокируют старт)**

1. №49 — доставка: курьер по городу (#28) на боевом выключен, «в регионы» (#6) бесплатна
   при любой сумме; в вёрстке курьер 200 ₽ и ТК 300 ₽ до 5 000 ₽. Что оставляем.
2. №50 — часы Тюмени (админка «Пн–Вс 09–20», вёрстка «Пн–Пт 9–20, Сб–Вс 10–19»).
3. №51 — нужен ли на сайте второй телефон 8 (905) 099-97-77. Почта уже `king-oil@yandex.ru`.
4. №53 — подразделы мега-меню, которых нет в каталоге (антифриз G11 / G12, виды фильтров,
   лампы H4 / H7): заводим категории или убираем пункты.
5. №54 — фильтры «Тип масла», «Бренд», «Допуск», «Объём»: заводим характеристики в CS-Cart
   или считаем их из названия / категории, как сделано в статике.
6. №56 — скрыть мусорные категории и демо-характеристики на стенде.
7. №47, №45, №31, №32 — тексты про оплату картой, адреса соцсетей, ключ Яндекс.Карт,
   отдельные юридические документы.
8. Опечатки в названиях товаров (список выше) — правит заказчик в админке.

**Перенос на стенд (витрина `company_id = 1`)**

9. Клонировать тему `responsive` → своя тема, назначить только витрине «Омск»; три чужих
   витрины не трогать.
10. Перенести фундамент файлами темы: токены, локальные `.woff2`, SVG-спрайт,
    `base.css` / `components.css` / `pages.css` / `shop.css`.
11. Шапка, подвал, мобильное меню, раздел «Каталог» — на живое дерево категорий по
    `data-cs-category` / `data-cs-page`.
12. Листинг категории — на штатный список товаров: плитка по разметке `.product-card`,
    фильтры по решению №54, Searchanise учесть.
13. Карточка товара — характеристики через features, чипсы объёма по правилу «соседи
    по названию» (или вариации, если заказчик заведёт характеристику «Объём»).
14. Корзина, оформление, заказ, личный кабинет — перестилизовать штатные шаблоны;
    `js/store.js` выбрасывается, ключ позиции — `product_id`; способы получения по
    `data-cs-shipping`, точки — `data-cs-store`, статусы — `data-cs-status`.
15. Статические страницы — в CMS-страницы по `data-cs-page`; «Отзывы» — новая страница.
16. Поиск — подсказки и выдача от Searchanise / штатного поиска вместо `KO_PRODUCTS`.
17. Раскладки и блоки в Layout-редакторе для витрины 1.
18. Обновить данные стенда с боевого (отставание на месяц), прогон 1440 / 1024 / 768 / 375,
    приёмка, перенос темы на боевой сервер.
