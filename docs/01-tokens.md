## Сетка

| Параметр | Значение |
|---|---|
| Артборд десктоп | **1900 px** (в названии фреймов написано «1920», но реальная ширина 1900) |
| Боковое поле | **240 px** |
| Контейнер | **1420 px** |
| Артборд мобайл | **375 px** |
| Сетка каталога | 3 колонки по **460 px**, гэп по горизонтали **20**, по вертикали **48** |
| Карточка товара | галерея **620** + инфоблок **736**, между ними **64** |
| Футер | 4 колонки: 420 / 198 / 132 / 263, верхний отступ 80 |

```css
.container {
  max-width: 1420px;
  margin-inline: auto;
  padding-inline: 20px; /* на широких экранах поля добираются автоматически */
}
```

⚠️ Не задавай `padding: 0 240px` жёстко — 240 это поле только на ширине 1900. Правильно: контейнер 1420 по центру.

## Отступы

Шкала: **0, 4, 8, 10, 12, 16, 18, 20, 24, 32, 40, 48, 64, 80, 120, 160, 240**

Практика применения в макете:
- 8 / 12 / 16 — внутри контролов и мелких групп
- 20 — гэп сетки по горизонтали
- 24 / 32 — между элементами внутри блока
- 48 — гэп сетки по вертикали, отступ заголовка секции от контента
- 80 / 120 — вертикальные отступы между секциями
- 240 — боковое поле артборда

## Радиусы

**Все токены радиусов = 0.** `radius-none`, `radius-small-1/2/3`, `radius-medium-2`, `radius-large-1` — везде ноль. Единственное исключение — `radius-max` = 9999 px: круглые подложки иконок в модалках и аватары в отзывах.

То есть кнопки, инпуты, карточки, бейджи, модалки — **всё с прямыми углами**. Это принципиально для стиля; если верстаем поверх готовой темы CS-Cart, скругления придётся принудительно сбрасывать.
